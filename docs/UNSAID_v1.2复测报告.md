## 3. 当前版本仍然存在的问题

### 3.1 【中】A6 只修了一半：门口那句话仍然能翻转结局（实测 21.6%）

**受控实验**（把一局玩到 `goodbye`，深拷贝局面，再从**同一局面**分别重放每个选项）：

| 指标 | 实测 |
|---|---|
| 有效试验（≥2 个可点选项） | 1958 |
| 各选项给出**不一致**结局的傍晚 | **422（21.6%）** |
| 与"这一屏不存在时的结局"不同的选项实例 | 597 |

按选项拆分（哪些选项在改变结局）：

| 门口选项 | 改变结局的次数 |
|---|---:|
| 说心里话 | 264 |
| 沉默 | 128 |
| 回头抱她 | 97 |
| 附和 | 55 |
| 阴阳怪气 | 53 |

典型翻转：`MOM'S LEDGER — HANDED BACK → THE OUTSIDER`、`THE OUTSIDER → AN ORDINARY YEAR`、`THE SENSIBLE ONE → THE OUTSIDER`。

**为什么权重压到 0.35 还不够**：机制总表 §14.6（第 882 行）给的理由是——

> "现在它只贡献 3–4 点量表变化，而门前的最小分差通常在 10 点以上。"

这句话有两个错：

1. **UNSAID 不受权重保护到"无害"的程度。** `applyVerb()` 里每个非 `unsaid` 动词都会加 `BASE_UNSAID = 1`，权重只乘动词自身的 `fx.unsaid`。所以"沉默"在门口仍然是 `round(3×0.35) + 1 = 2` 点 UNSAID，"附和/移话题/敬酒"也都是 +1~+2。而 UNSAID 上挂着**两个结局阈值**：`≥6 → 明年不回来了`、`≥8 → 外人`。2 点就足以跨过它们。
2. **"最小分差通常 10 点以上"不是判据。** 结局条件几乎全是**单条量表的阈值**（UNSAID ≥6/≥8、真我 ≤35、孝 ≥85、面子 ≥70）。跨阈值只需要 1 点，与其它量表差多少无关。实测沉默之所以能翻转 128 次，正是它把 UNSAID 从 5 推到 7、从 6 推到 8。

**建议**：门口节点不要只压权重，而是要么在应用效果前就把结局判定冻结（`resolveEnding()` 先算好、门口的选择只写 coda），要么让门口节点完全不改 UNSAID（把 `BASE_UNSAID` 在该节点跳过）。这样"只决定最后一行"才是真的。

**文档侧**：机制总表 §14.6 第 869 行"且它**不改变拿到哪个结局**"、第 880 行"压低权重 + 改成只写尾行之后，这一节成立"，以及设计文档 §6.1 的验收标准（"把这一屏删掉，结局应该几乎不变"），目前都还不成立。

### 3.2 【中·新引入】失败一栏的压力箭头会指反

v1.2 新加了"会失败的动词同时显示成功与失败两组结果"（`⚄7+ … ✗ …`），这是好改动。但失败那一栏的算法写错了：

```js
// index.html   fxText()：提示里的"失败"一栏
bad[k] = (k==="face"||k==="filial") ? -Math.abs(good)-2
       : (k==="stress") ? 4 : good;          // ← 压力一律写成 +4（"Stress↑"）
```
```js
// index.html   choose()：技能检定真的失败时
delta.stress = (delta.stress||0) + 6;        // ← 是"原值 + 6"，不是"变成 4"
```

对 `joke`（幽默化解）而言两者一致（`applyVerb` 里失败时压力就是 `4`）。但 `RISKY_VERBS` 里还有两个动词的基础压力是**负的**：`passive` 阴阳怪气 `−8`、`scapegoat` 甩锅 `−7`。它们检定失败后是 `round(−8×m) + 6`，在大多数系数下仍然是**负数**，而提示画的是 `Stress↑`。

**解析验证**：32 个"动词 × 亲戚"组合里 **13 个不一致**（阴阳怪气 × 全部 8 位亲戚，甩锅 × 5 位）。

| 组合 | 提示 | 引擎实际 |
|---|---|---|
| 阴阳怪气 / 妈妈 | Stress↑ | −2 |
| 阴阳怪气 / 奶奶 | Stress↑ | −4 |
| 阴阳怪气 / 姑妈 | Stress↑ | −5 |
| 甩锅 / 奶奶 | Stress↑ | −11 |
| 甩锅 / 爸爸 | Stress↑ | −1 |

**行为验证**（把 `S.self` 压到 10 以下让修正值变成 −2、几乎必定检定失败，然后点阴阳怪气）：**30/30 次**提示都说 `Stress↑`，实际压力变化分别是 −7 / −1 / −4 / −9 / 0 …——**没有一次方向是对的**。

**影响**：出错的位置恰好是最需要提示的地方（8 张旧账 + 摊账本，全都是带检定的节点）。一个把玩家教反的提示，放在一个主题就是"你永远无法确认自己读懂了那句话"的游戏里，格外刺眼。

**建议**：`bad.stress = (verb === "joke") ? 4 : good + 6;`，或者对"失败后仍为负"的动词干脆不画压力箭头。顺带一个同类小问题：失败时引擎会把真我的收益乘 0.4，而提示仍按成功值画箭头，于是"硬刚"失败时提示可能画 `Self↑↑` 而实际只有 `↑`（8 位亲戚里有 5 位会这样）。
