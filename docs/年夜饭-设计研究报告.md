# 年夜饭 · 选择驱动叙事 Roguelike｜设计研究报告

> 目标：从《Reigns》《中国式家长》《极光迪斯科》《Slay the Princess》《Hades》等作品中提取**可迁移的具体规则与数字**，用于一款"纯选择、无战斗、结局由累积选择决定"的浏览器年夜饭游戏。
> 说明：本文所有具体数字均标注来源；无法核实的一律标 **UNVERIFIED**。

---

## 一、18 条可迁移设计模式

| # | 模式名 | 具体机制 | 由谁证明 | 映射到年夜饭 |
|---|---|---|---|---|
| 1 | **双向量条（Bidirectional Meters）** | 4 条量条（教会/人民/军队/国库），每条 0–100；任一量条归 **0 或满值都死**。每次选择对每条量条施加 ±5～±25 的固定增量 | Reigns（Nerial，2016）[1] | 3–4 条"饭桌电量"：面子 Mianzi / 孝道 Filial Piety / 真相 Truth / 和睦 Harmony。任一条触顶或触底 = 饭桌崩盘 |
| 2 | **左右二选一（Tinder Swipe）** | 每张卡只给左右两个方向，无第三种可能；选择被手势化以降低阅读成本 | Reigns [1] | 保留二选一作为**默认节拍**（0.8 秒可读），关键节点才升到 3–4 选项 |
| 3 | **内容概率池（Filtered Deck, not Fixed Order）** | 每张卡带前置条件；抽卡前**剔除所有与当前国状态不符的卡**（未婚则所有王后卡被移除）。玩家分不清"随机卡"与"顺序卡" | Reigns，主创 François Alliot 亲述 [1] | 事件池按 `tag` 过滤：`requires: marry` / `requires: 二舅在场` / `exclude: 已和解`。这是"每次都有新故事"的核心 |
| 4 | **双层故事语法** | 先写单次卡 → 再围绕一段时间写"小故事卡组" → 再叠加新角色与活动 | Reigns [1] | 三层内容：**微卡**（单次冲突）、**弧卡**（3–5 张讲完一个亲戚的事）、**角色卡**（大姨/父亲/表弟的连续线） |
| 5 | **冲突内心之声（Conflicting Inner Voices）** | 技能不只是数值，而是**会主动插话、互相反驳的角色**。玩家被迫与自己辩论 | Disco Elysium（ZA/UM，2019）[4] | 5 个声音：**体面**（要面子）、**孝**（要顺从）、**真**（要说真话）、**怯**（怕冲突）、**记**（记仇/记得旧事）。每个声音有固定偏见领域 |
| 6 | **主动口头插话（Passive Check）** | 声音不需要玩家操作就自己开口，只要它的等级过了门槛；门槛 ≈ 检定难度 | Disco Elysium [4] | 量条本身触发插话：面子 >70 时"体面"自动开口，Truth <20 时"怯"抢答 |
| 7 | **2d6 + 技能 vs 难度** | 投 2 个六面骰；**投出 2 必败、12 必胜**。难度档：6 Trivial / 8–9 Easy / 10–11 Medium / 12 Challenging / 13 Formidable / 14 Legendary / 16 Godly / 18–20 Impossible | Disco Elysium [4] | 用**明骰**做高潮节点（"你要不要说出这句话？"），用**隐藏量条**做日常节点 |
| 8 | **失败也是内容（Failure-as-Content）** | 白检定可重试、红检定一次性锁死；**失败照样推进剧情**，只是推进到另一条分支 | Disco Elysium [4] | 说错话不是 Game Over，而是**换一条更尴尬但更有戏的路**。永远不重开 |
| 9 | **知识即进度（Knowledge as Progression）** | 玩家的**知识**（谁怕谁、哪句话会炸、去年发生了什么）而非数值，才是跨周目的真正成长 | Hades（Supergiant，2020）[5] | 第 2 周目玩家已知"三舅会问工资"，可以直接预判。**不给属性，给信息** |
| 10 | **羁绊计量表 + 礼物（Bond Meters）** | 蜜露 Nectar 满 **6 心**触发锁心；后半段用仙酒 Ambrosia 送到 **10 心**，解锁伴偶 Call 与专属对话 | Hades [7] | 每个亲戚一条 0–6 心：0 冷漠 / 2 客套 / 4 交心 / 6 和解。送礼 = 敬酒、夹菜、递烟 |
| 11 | **图鉴（Codex as Collection）** | 图鉴条目靠"遇到过"解锁，让重复内容也变成收集 | Hades [5] | **亲戚档案**：每次遇到新的一句台词 / 一个新的旧事碎片就解锁一格。让"重开"有实感 |
| 12 | **代际继承（Generational Loop）** | 每解锁一个特长图鉴，下一代天赋 **+1 点**；每解锁一个新职业图鉴大幅加成。**第 5 代初始天赋 ≈ 第 1 代的 6–7 倍** | 中国式家长（墨鱼玩，2018）[2][3] | **年份周目**：2004 → 2014 → 2024。上一代的选择变成这一代的"家族设定"（父母的旧伤、家里的规矩） |
| 13 | **愿望系统（The Wish）** | 孩子提出愿望，玩家选择满足或拒绝；**不满足无惩罚**，满足则加属性与行动力 | 中国式家长 [3] | 弟弟/妹妹或童年的"你"提出愿望。**不强迫玩家当好人**，因此选择才有意义 |
| 14 | **面子对决（Face Battle）** | 每代有 **5 次面子挑战**；对手是亲戚的孩子；胜负由特长稀有度决定（稀有/史诗/传说三档）。面子用来买东西 | 中国式家长 [2][3] | **敬酒对决 / 成绩对比 / 相亲审问**三段式。稀有度 = 你人生里攒下的"谈资" |
| 15 | **事件卡池过滤** | 池子按现状剔除不合法卡，玩家每次见到的是"全新的、但都合理的"卡 | Reigns [1] | 事件 bank 分 act / tag / requires / exclude 四维。**同类事件同一局最多出现一次** |
| 16 | **三幕升级曲线** | 每幕一个 boss，地图约 50 层，3 幕 + 1 隐藏幕 | Slay the Spire | **8 道菜 = 8 个 act 节点**：凉菜（破冰）→ 热菜（试探）→ 主菜（冲突）→ 汤（真相）→ 水果/茶（收尾/和解或决裂） |
| 17 | **种子化洗牌（Seeded Shuffle）** | 用固定种子的 PRNG 决定抽卡顺序，同一 seed 可复现同一局 | 通用 roguelike 实践 | Vite + `seedrandom`。**课堂上可用 `?seed=20240210` 复现同一局**，便于展示与讲解。⚠️ 本轮未能核实具体库版本，属工程常识 |
| 18 | **不可逆门（The Two Doors）** | 关键时刻给一个"走进去就回不来"的门；游戏**记住**你上次走了哪扇 | The Stanley Parable（Galactic Cafe，2013 / Ultra Deluxe 2022） | 年夜饭只有一个不可逆节点：**"你到底说不说那件事"**。说了，剩下 3 道菜全变味 |

## 二、量条经济建议

**数量：3 条，不要 4 条。**
Reigns 用 4 条是因为中世纪四权分立是天然隐喻；年夜饭的张力只有三条主线：**面子 / 和睦 / 真相**。第 4 条会稀释每次选择的清晰度（"我到底在牺牲什么"说不清）。

**范围与增量：**

- 范围 **0–20**（不是 0–100）。理由：玩家能一眼读出"我离死还有几点"，而 0–100 只能读出感觉。
- 普通卡增量 **±2 ~ ±4**；弧卡（亲戚线）增量 **±5 ~ ±7**；高潮卡 **±8**。
- 起始值 **10 / 10 / 10**（正中）。这制造了 Reigns 的核心体验：你永远在两边都危险的位置上。
- **危险区**：≤3 或 ≥17 时，该量条的"声音"开始插话（对应模式 6），提前预警但不直接杀死。

**死亡机制：任一量条到 0 或 20 = 这一年的年夜饭结束**（进结局，不重开）。Reigns 的"死亡"之所以不烦人，是因为死得**快且信息量大**。

**⚠️ Reigns 式"量条触顶而死"的失败模式（必读）：**
四个量条都是 0–100 且**两端都死**，导致最优策略退化为"把四条都压在 40–60 之间"——玩家不再扮演国王，而是在**做均衡器管理**。所有卡片的道德内容被压缩成"这个选项给哪条 +10"。这就是"3 局通关"的根源：一旦玩家发现中位数安全，剩余的意义全部蒸发 [1]。

**四条防"3 局通关"的具体规则：**

1. **不对称惩罚**：三条量条触顶/触底的后果不同。面子归零 = 被逐出家门；和睦归零 = 掀桌；真相触顶 = 说穿了，所有人都受伤。玩家无法用"保持中位"统一处理。
2. **隐藏量条**：**第 4 条隐藏量条不显示**（例如"母亲的疲惫"或"父亲的病"）。它只在结局结算时揭晓。玩家在无信息下做选择，第二周目才知道自己一直在动它。
3. **时间压力替代即时死亡**：8 道菜 = 8 个节点，**菜序推进不可逆**。不是"触顶就死"，而是"触顶则剩下的菜全部重写"。这比死亡更有情感重量。
4. **记忆惩罚**：同一量条连续 3 次被推向同一方向，触发**固化（Hardening）**——该量条被锁定在危险区，不能再被同一类选项拉回。这直接打击"反复横跳"的套利策略。

## 三、技术栈对比与裁决

| 栈 | 语言 | 状态管理 | 条件/随机 | 存读档 | 构建体积 | 浏览器/投影仪可靠性 | 学习曲线 | 许可/风险 |
|---|---|---|---|---|---|---|---|---|
| **ink + inkjs** | ink 脚本 + JS | `VAR` / `LIST` / `visit_count` | `shuffle` / `seq` / `RANDOM()` / `visit_count` | `story.state.toJson()` 可序列化 | inkjs **2.4.0**，npm 包 6.6 MB（含 sourcemap/CLI），MIT，0 依赖 [6] | ✅ 可无服务器跑（模板 `browser_serverless`）；加载 JSON 需服务器（CORS）[6] | 中（作家友好，需学 ink） | MIT，最安全 |
| **Twine 2 + SugarCube** | TwineScript | `$vars`、`StoryInit`、`State.variables` | `<<if>>`、`random()`、`<Array>.shuffle()`、`<Array>.randomMany()` | `Save.browser.slot.*`（多槽）、`Save.browser.auto.*`（自动存档）、`Save.disk`、`Save.base64` | 单个自包含 HTML | ✅ 最强：双击 HTML 即跑，零服务器 | 低（非程序员可用） | SugarCube **2.37.3（2024-07-27）** 仍在维护 [8] |
| **Ren'Py 8 Web** | Python | `default` 变量 + rollback | Python 全功能 | 顶配：多槽 + 回滚 + 截图 + traceback save | **大**（WebAssembly；官方提示文件 >50MB 不再被缓存） | ❌ **官方文档明说"从该文件夹直接运行不受支持，必须由 web 服务器托管"**；仅 Beta；无多线程、无网络 [9] | 中 | MIT |
| **Godot 4 HTML5** | GDScript | 节点/场景 + 自建 | 全功能 | `user://` 依赖 IndexedDB，隐私模式失效 | 4.3 Web `.wasm` **约 40 MB 未压缩 / 约 5 MB Brotli** [10] | ⚠️ 需 WASM + **WebGL 2.0**；官方**不推荐 Safari**；单线程导出（4.3 起默认）免 COOP/COEP；**多线程导出必须 COOP/COEP 头，否则"项目完全无法运行"** [11] | 高 | MIT |
| **Yarn Spinner for Web** | Yarn + JS/TS | 变量存储 | 支持 | 需自建 | 小 | ✅ | 中 | MIT（未在本轮核实） |
| **纯 TS + Vite** | TypeScript | 自建（Zod 校验事件 bank） | `seedrandom` 种子洗牌 | `localStorage` / `IndexedDB` | **最小**（几十 KB～几百 KB） | ✅ 最可控：纯静态文件，`file://` 或任意静态服务器 | 高（要自己写引擎） | 全自由 |

**裁决：**

- **3 人学生团队、6–10 周 → Twine 2 + SugarCube。** 理由：零服务器、双击 HTML 就能在投影仪上跑（这是课堂最大的风险点）；SugarCube 2.37.3 内置 `Array.shuffle()`、`random()`、多槽存读档与自动存档，事件 bank 的洗牌需求**开箱即用**，不需要自己写 PRNG [8]。代价是版本控制不友好、大故事会卡。
- **独狼且会写代码 → TypeScript + Vite + Zod + 种子 PRNG。** 理由：构建体积最小、离线绝对可靠、事件 bank 可以用 YAML/JSON 数据驱动、种子可复现课堂演示。但**必须自己实现叙事引擎**（条件、变量、存读档）。
- **不推荐**：Godot 4（40 MB WASM + 必须 WebGL 2.0 + Safari 不可靠，投影仪风险过高 [10][11]）；Ren'Py Web（**官方明说不能从文件夹直接运行**，课堂断电即死 [9]）。
- 若团队里已有作家、想保留 ink 的写作体验：**inkjs 2.4.0（MIT、0 依赖、6.6 MB 包）+ Vite**，用 `browser_serverless` 模板把编译好的 JSON 内联进 bundle，即可绕开 CORS 离线运行 [6]。

**离线/课堂安全清单：**

- Twine/SugarCube、纯 TS+Vite：**U 盘拷 HTML 即可，零网络**。
- inkjs（内联 JSON）：同样可零网络。
- Ren'Py Web / Godot Web：**必须本地服务器**。`python -m http.server` 或 `npx serve`（注意：Ren'Py 官方明确说"从文件夹直接运行不受支持" [9]）。
- Godot 多线程导出若缺 COOP/COEP 响应头，**项目完全无法运行** [11] —— 这是最容易在课堂上翻车的坑。

## 四、课堂现场演示协议（观众投票版）

**技术模型（Jackbox 模式）：** 主机跑游戏，观众用手机浏览器打开 `jackbox.tv`，输入房间码当控制器，**不装 App**。Quiplash 的 Audience 模式支持**最多 10,000 人**同时投票且真实影响结果；3–8 人是核心玩家，超出的人自动进观众席 [12]。

课堂上用一个更轻的降级方案即可：**一台投影仪 + 一个二维码 → 网页投票 → 实时票数条**。备用方案：举手 / ABCD 卡片 / Plickers（无网可用）。

**一分钟一分钟的 3 分钟形状（无教程）：**

| 时间 | 画面 | 做什么 |
|---|---|---|
| **0:00–0:20** | 冷开场：一张卡，一句话，两个方向 | 不讲规则。只念卡面文字。第一题必须是**所有人都能秒懂的冲突**（"妈问你今年存了多少钱"） |
| **0:20–0:50** | 实时票数条 | 观众扫码投票（限 20 秒）。**主持人只报票数差**，不解释 |
| **0:50–1:40** | 连做 3 题 | 每题只给 2 个选项；每题后**只显示量条变化的方向**，不显示数字 |
| **1:40–2:20** | **唯一的不可逆节点**（模式 18） | 大屏问："你要不要说那件事？" 投票后，剩下 3 道菜全部改色/改写。**这是情感落点** |
| **2:20–2:50** | 结局卡 | 一张结局画面 + 一句由量条组合派生的文案。**不给分数，不给"正确答案"** |
| **2:50–3:00** | 静默 | 留 10 秒不说话 |

**关键规则：**
1. **一屏一决策**：每个画面只有一个问题、两个选项。选项文案 ≤12 字。
2. **选项数 = 2**。现场有静默成本，3 个以上选项会产生"死空气"（dead air）。只有不可逆节点允许 3 个。
3. **前 90 秒必须出现一个情绪高点**：不要用教学开场。第一道菜（凉菜）就应该是"有人问你一个你不想回答的问题"。
4. **兜底**：投票服务挂掉 → 举手。演示者永远准备好一句"举手吧"。

## 五、家庭创伤题材避坑清单（20 条）

**避免 misery porn（苦难展览）：**
1. 不给"惨"特写。创伤靠**回避和沉默**表现，不靠嚎哭。
2. 每 3 个冲突事件里，强制插入 1 个**温柔/好笑**的事件。Reigns 的卡池之所以能撑 2 小时，是因为它允许自己好笑 [1]。
3. 禁止把家暴、自杀、成瘾当"选项后果"。
4. **不写施害者的内心独白**去替他们开脱，也不写他们的辩白。
5. 结局里至少留一处**具体的、不解决的东西**（比如父亲就是不会道歉）。不解决才是诚实。

**避免刻板印象（stereotyping）：**
6. 亲戚不能"一个标签一个"。"重男轻女的奶奶"必须同时是"记得你小时候吃的第一口菜的人"。
7. 地域/阶层不靠口音、服饰符号化，靠**具体的物**（黄冈密卷、麻将、酱菜罐）[3]。
8. **父母双方都要有能动性**：不做"沉默的父亲 + 歇斯底里的母亲"这个公式。
9. 至少一个亲戚**真心对你好且不图回报**，否则整个家庭变成怪物收容所。
10. 允许玩家扮演**冷漠的一方**。只允许"受害者"视角会变成说教。
11. 男女亲戚的台词量、复杂度、说话长度要大致均衡。
12. 不把"重男轻女"处理成一关要打败的 boss，处理成**一个你每天都要绕过去的路障**。

**避免说教（moralizing）：**
13. **没有 golden path**。每个结局都必须有辩护空间。
14. 永远不出现"你这样做是错的"。用第三方转述替代旁白评判（"你妈后来跟邻居说……"）。
15. **不给分值**，不给"和解指数"。[12] 的规则同理：观众投票影响结果，但游戏不宣布谁对。
16. 沉默、离席、"我不想聊这个"必须都是合法选项。
17. **反向选项也要有尊严**：让"顶嘴"和"顺从"都能写出好台词，不要一边明显写得更用心。

**玩家/主角分歧（ludonarrative）：**
18. 明确允许玩家**违背主角利益**："你不想说，但你的手已经把杯子放下了。" 用**动作先于意图**制造自我争论（Disco Elysium 式的声音分裂 [4]）。
19. 主角有自己的记忆，玩家没有。用"记"这个声音把**信息差**变成张力：玩家不知道，主角知道，声音替他泄露 [4]。
20. 结局由**累积选择的分布**决定，而不是最后一个选择。让玩家在结局里**认得出自己前面做了什么**，这是唯一让"选择有意义"的证明。
