## 1. 核心命题，以及机制怎么证明它

> **东亚家庭的矛盾，主要不是"爱不爱"的问题，而是"翻译"问题。**
> 爱是真的，控制也是真的，而它们用的是同一种语言——所以孩子无法反驳。

游戏的每一条机制都必须能翻译成一句关于家庭的断言。做不到的机制就不该存在。

| 机制 | 它证明的那句话 |
|---|---|
| 双声道对话 | 你说出口的和你心里想的，是两件不同的事；而只有第一件会被听见 |
| 未说 UNSAID | 压抑不会消失，它只会转移——转成失控，或转成压力 |
| 漏水 | 你甚至控制不住自己说出什么 |
| 固化 | 你重复太多次同一种反应，它就成了你的性格 |
| 压抑的复利 | "保持中立"本身是有代价的 |
| 人情账本 | 恩情是真的，越界也是真的，它们是同一笔账 |
| 账本两边不同步 | 你们记的从来不是同一本账 |
| 关系网涟漪 | 家庭不是一对一关系的总和，它是网，拉一根线别处都会动 |
| 字幕置信度 | 有时候翻译得通，有时候不通，而你永远无法 100% 确认 |
| 结局判定顺序 | 你是什么人，比你最后说了什么更重要 |
| 轮回 | 这不是"他们"的问题，是"我们"的问题 |

## 2. 一次 Run 的完整结构

一次 Run = **一年 = 一顿年夜饭**。约 17 个决策点，12–20 分钟。

### 2.1 时间

- 开局 **18:30**
- 每次选择推进 `8 + random(0..8)` 分钟（约 8–16 分）
- 逃席分支额外 +10 分钟
- 结束约 **22:00**

### 2.2 八个幕与 16 个槽位

排期表在 `buildSchedule()` 里，固定顺序，**不可回头**：

| 槽 | 类型 | 内容 | 幕 |
|:--:|---|---|:--:|
| 1 | 节点 | `arrive` 进门，妈妈开门 | 1 冷盘 |
| 2 | 节点 | `orange` 奶奶塞橘子 | 1 |
| 3 | 抽牌 | 话题牌（第 2 幕池） | 2 盘问 |
| 4 | 抽牌 | 话题牌（第 2 幕池） | 2 |
| 5 | 节点 | `followup` 妈妈接话："我说让她考个编，她不听" | 2 |
| 6 | 抽牌 | 话题牌（第 3 幕池） | 3 比较 |
| 7 | 节点 | `xiaochen` 二姨："隔壁小陈家孩子" | 3 |
| 8 | 抽牌 | 话题牌（第 3 幕池） | 3 |
| 9 | 节点 | `toast` 大舅："给爷爷奶奶说两句" | 4 敬酒 |
| 10 | 节点 | `escape` 逃席——**只能去一个地方** | 5 门外 |
| 11 | 节点 | `oldscore` 旧账（从 8 张里抽） | 6 旧账 |
| 12 | 节点 | `reckoning` 摊账本 | 6 |
| 13 | 抽牌 | 话题牌（第 7 幕池） | 7 未来 |
| 14 | 节点 | `wedding` 二姨："什么时候结婚" | 7 |
| 15 | 抽牌 | 话题牌（第 7 幕池） | 7 |
| 16 | 节点 | `goodbye` 门口最后一句 | 8 门口 |

**外加两个可能被插入的节点**：`flood`（决堤，由 UNSAID 触发，插在任意节点之前）和四个逃席子场景（`esc_kitchen` / `esc_balcony` / `esc_bath` / `esc_cousin`，在槽 10 内部展开，不占槽位）。

### 2.3 开局随机化

- **话题牌**：从 21 张里洗牌，取前 10 张作为本局牌堆
- **旧账**：从 8 张里洗牌，取前 4 张
- **话题牌的发言人**：每张牌带一个候选亲戚列表，抽到时随机选一个说话
- **旧账的归属**：固定（每张旧账绑定一个亲戚）

### 2.4 提前结束

`advance()` 每次运行前先检查，满足任一条件立刻进结局：

| 条件 | 后果 |
|---|---|
| 压力 ≥ 100 | 崩，本局提前结束 |
| 面子 ≤ 0 | 丢人，本局提前结束 |
| 真我 ≤ 0 | 透明，本局提前结束 |

## 3. 状态系统

### 3.1 四条可见量表

内部数值空间 **0–100**，界面显示为 **10 格 + 精确数值**。

> **v1.2 起显示 `当前值/最大值`**（如 `FILIAL 94/100`、`UNSAID 11/10`）。
> 最初的设计是"永不显示精确数字"，理由是数字会让玩家开始"算"而不是"感受"。
> 实测下来，格子太少反而读不出方向——**0–100 的数字比 10 格更容易一眼判断**，所以改为两者并列。
> **选项上的效果提示仍然只给箭头不给数字**，那是真正会诱发计算的地方。

| 量表 | 英文 | 初始 | 危险区（变红闪烁） | 触底后果 |
|---|---|:--:|:--:|---|
| 面子 | FACE | 50 | ≤20 或 ≥80 | ≤0 → 本局结束 |
| 孝 | FILIAL | 50 | ≤20 或 ≥80 | ≤0 → 开启「断绝」结局线 |
| 真我 | SELF | 50 | ≤20 或 ≥80 | ≤0 → 「说心里话」永久失效 |
| 压力 | STRESS | 25 | ≥75 | ≥100 → 本局结束 |
| 未说 | UNSAID | 0 | ≥5 | 见 §8 |

危险区显示的状态标签（**两端用不同的词**）：

| 量表 | 条件 | 标签（中 / 英） |
|---|---|---|
| 面子 / 孝 / 真我 | ≤20 | `已耗尽` / `spent` |
| 面子 / 孝 / 真我 | ≥80 | `过满` / `overfull` |
| 压力 | ≥75 | `临界` / `critical` |
| 未说 | ≥5 | `5+` |
| 未说 | ≥10 | `决堤` / `flooding` |

> ⚠️ **v1.2 修正**：此前两端共用同一个词 `drained`（已耗尽）。
> 因为危险区判定是**两端**（≤20 或 ≥80），所以一个 **92/100 的真我会显示"已耗尽"**——
> 数值是对的，标签完全用反了。现在两端各有自己的词。

**关键设计**：没有一条量表指向"好"。
面子太高 → 你成了演员；孝太高 → 你成了透明人；真我太高 → 你伤了你爱的人。
玩家必须选择**要哪一种遗憾**，而不是追求最优解。

### 3.2 隐藏量表：妈妈的疲惫 MOM_FATIGUE

- **初值 50，界面上永不显示**
- **只在结局揭晓**，且不是一个数字，是一段画面

**四档揭晓画面（v1.1 起随数值变化）**：

| 疲惫 | 画面 |
|:--:|---|
| **< 30** | 她坐在没收拾完的桌子边上，脱了一只鞋，在揉脚。<br>*她每年都这样。你今年是第一次看见。* |
| **30–54** | ……脱了一只鞋，在揉脚。**围裙还没解。**<br>*厨房的水还在流。* |
| **55–79** | ……**两只鞋都脱了。没有揉脚，只是坐着。**<br>*盘子还在桌上。她没动。* |
| **≥ 80** | **她靠着椅背睡着了，穿着外套，灯还亮着。**<br>*没有人叫醒她。也没有人注意到她早就不说话了。* |

数值本身只以极淡的小字出现在统计行里（`Mom's fatigue 63`），和别的数字放在一起——
**上面的画面里一个字都不提数字**，那句"没有字幕。不解释。"才算数。

- 变化规则（在每次选择后结算）：

| 动作 | 疲惫 |
|---|:--:|
| 沉默 / 装傻 / 转移话题 | **+2** |
| 硬刚 / 甩锅 | **+5** |
| 敬酒夹菜 / 搬救兵 | **−3** |
| 每换一幕 | **+1** |

**用意**：玩家会精算四条看得见的量表，却从来不知道自己在消耗一个看不见的。而那个看不见的，恰恰是整晚在支撑这顿饭的人。

## 4. 双声道对话（The Two Channels）

每一屏同时呈现两件事：

```
┌────────────────────────────────────────────┐
│  MOM                                        │
│  “You're back. …You've gotten thinner.”     │
│  Literal                          conf 91%  │
├────────────────────────────────────────────┤
│  HOW DO YOU COME IN?                        │
│  A  AGREE     “Mom.” (hug her)              │
│               Face↑ Filial↑ Self↓ Stress↓   │
│  B  MAKE A JOKE  …                          │
├────────────────────────────────────────────┤
│  INSIDE — NEVER HEARD                       │
│  I was home four months ago.                │
│  Nobody is going to hear this.              │
└────────────────────────────────────────────┘
```

- 上半是**说出口的话**（玩家选）→ 影响量表
- 下半是**心里正在想的话**（NPC 永远听不到）→ **每个节点自动 +1 未说**

选「说心里话」以外的任何动词，都会额外 `UNSAID += 1`。
只有 `SAY THE UNSAID` 不额外加（它本身 −8）。

## 5. 应对动词总表（13 个）

基础效果（在乘对象系数**之前**）。缩写：面=面子 孝=孝 我=真我 压=压力 未=未说。

| 动词 | 英文 | 中文 | 面 | 孝 | 我 | 压 | 未 | 账本权重 |
|---|---|:--:|:--:|:--:|:--:|:--:|:--:|:--:|
| agree | AGREE | 附和 | +4 | **+8** | −6 | −6 | 0 | +6 |
| deflect | CHANGE THE SUBJECT | 转移话题 | +3 | +2 | 0 | −3 | +1 | +2 |
| confront | PUSH BACK | 硬刚 | **−10** | **−12** | **+12** | +10 | **−6** | −4 |
| passive | SAY IT SIDEWAYS | 阴阳怪气 | −3 | −5 | +5 | **−8** | +2 | 0 |
| dumb | PLAY DUMB | 装傻 | −4 | −3 | +1 | −4 | +1 | +2 |
| victim | PLAY THE VICTIM | 卖惨 | +2 | +5 | −4 | **+4** | +1 | +5 |
| scapegoat | DEFLECT THE BLAME | 甩锅 | +5 | +3 | **−8** | −7 | 0 | −6 |
| soften | SOFTEN | 示弱 | +2 | **+7** | +1 | −5 | 0 | +8 |
| joke | MAKE A JOKE | 幽默化解 | **+6** | +4 | +3 | −6 | 0 | +3 |
| ally | CALL FOR BACKUP | 搬救兵 | +2 | −2 | −2 | **−9** | +1 | +4 |
| ritual | POUR A DRINK | 敬酒夹菜 | **+6** | +6 | −3 | **−8** | +2 | +7 |
| silence | SAY NOTHING | 沉默 | −2 | +3 | **−4** | **+4** | **+3** | +1 |
| **unsaid** | **SAY THE UNSAID** | **说心里话** | **−8** | **−10** | **+15** | **−20** | **−8** | −2 |

### 5.1 三个平衡点

1. **沉默是最安全的，也是唯一会真正杀死你的。**
   它同时推高 UNSAID 和压力。新手一定会一直沉默，然后崩掉或者变成透明人。这是设计好的第一课。

2. **「说心里话」是唯一能真正减压的选项，也是唯一会真正伤人的。**
   压力 −20 和真我 +15 是全游戏唯一的巨额回血与成长，代价是孝 −10、面子 −8。
   **这一行数字就是整个游戏的论点。**

3. **不同动词对不同亲戚效果不同**（见 §6），所以同一个按钮在不同人身上有不同的重量。

### 5.2 解锁条件

`SAY THE UNSAID` 只在 **UNSAID ≥ 6 或 压力 ≥ 70** 时可用。

`goodbye` 节点的特殊版本（"妈，那件事，我不怪你"）额外要求：已解锁秘密 **k1 / k11 / k7** 之一。

**几条读法**：
- **对奶奶硬刚代价翻倍**（2.0），**甩锅给奶奶代价 2.5 倍**——全游戏最不划算的操作，也是很多人真会做的操作
- **幽默对外人（表哥女友）特别有效**（1.6）——在"外人"面前，全家都想显得随和
- **示弱对二姨几乎无效**（0.4）——她不吃这套
- **敬酒夹菜对爸爸和大舅最有效**（1.5）——这是他们唯一听得懂的语言

### 6.1 每个亲戚的话语权（clout）

固定值，不随游戏变化。决定"这个人说的话有多少人听"。

## 7. 骰子判定（2d6）

有两处用骰子：**「幽默化解」**每次都掷，**高风险节点上的特定动词**要过一次技能检定。

### 7.1 幽默化解 · 2d6，掷 7 以上成功

```
2d6 ≥ 7  →  成功（21/36 ≈ 58.3%）
2d6 ≤ 6  →  失败（15/36 ≈ 41.7%）
```

| 结果 | 面子 | 孝 | 真我 | 压力 | 未说 |
|---|:--:|:--:|:--:|:--:|:--:|
| **成功** | +6 | +4 | +3 | **−6** | +1 |
| **失败** | **−8** | **−6** | +3 | **+4** | +1 |

**期望值**：

```
面子：0.583 × (+6) + 0.417 × (−8) = +0.2   ≈ 中性
孝　：0.583 × (+4) + 0.417 × (−6) = −0.2   ≈ 中性
压力：0.583 × (−6) + 0.417 × (+4) = −1.8   （正收益）
```

**这才是"方差牌"该有的样子**：面子和孝大致中性，压力上有正收益——所以它值得赌，但赌错会疼。

> ⚠️ **v1.0 的历史教训**：最初的阈值是 9（成功率 27.8%），期望值在每一条量表上都是负的——一个标着"赌一把"的按钮实际是**严格劣势策略**。实测印证：全程开玩笑只有 57% 摸到「外人」。改成 7 之后是 **70.3%**。

### 7.2 技能检定 · 高风险节点

带 `check` 字段的节点（**全部 8 张旧账，难度 11；摊账本，难度 12**），当玩家选以下四个动词之一时触发：

```
RISKY = 硬刚 / 阴阳怪气 / 幽默化解 / 甩锅

2d6 + 修正值  vs  难度
修正值 = clamp(⌊(真我 − 50) ÷ 20⌋, −2, +2)

失败时：面子、孝 变成 −(|原值|) − 2
        真我收益 ×0.4
        压力 +6
        该亲戚好感额外 −8
        屏幕显示一行红字：It didn't land.
```

**真我越高，越敢把话说死，也越容易接不住。** 这是唯一一处让真我"反过来咬你"的地方。

实测：约 **9%** 的高风险选择会检定失败（`小样本 19/214`）。

## 8. 四条隐藏的状态规则

这四条不在界面上，但决定了大部分结局。

### 8.1 漏水 Leak（UNSAID 5–9）

> 选牌时，**第一个「附和」选项会被系统悄悄替换成「阴阳怪气」**，且不提示。

- 按钮的**外观、动词标签、效果提示与真正的「附和」完全一致**（v1.2 起；此前有一个红框，等于提前告诉玩家了）
- 实际执行 `passive` 的效果
- **选完之后**才推送一条红色提示：`▸ You meant to agree. That is not what came out.`
- ⚠️ 机制总表 v1.0 曾写"额外扣 `FACE −3`（被发现）"——**代码里从来没有这条**，现已在文档中删除

**这是整个游戏最好的机制隐喻**：压抑不会消失，它只会以你无法控制的形式泄漏出来。
**而你连"我控制不住自己"这件事，都是事后才知道的。**

### 8.2 决堤 Flood（UNSAID ≥ 10）

> 强制插入 `flood` 节点。所有常规选项消失，**只剩一个按钮**。

```
   ▓▓▓ UNSAID 11 ▓▓▓
   你听见自己说：
   「那你当时为什么不让我去？」
                    [ 说 出 口 ]
```

效果：`面子 −8，孝 −10，真我 +15，压力 −20，UNSAID 归零`

并且置位 `flooded = true`——**一局只会发生一次**。

> **玩家失去选择权的那一瞬间，就是全游戏最难受的一瞬间。**

### 8.3 固化 Hardening

三个反应组，**同组连续 3 次 → 该组固化**（每组每局只固化一次）：

| 组 | 包含动词 |
|---|---|
| 顺从组 | agree / soften / victim |
| 攻击组 | confront / passive |
| 失语组 | silence / dumb |

选任何**不属于该组**的动词，会把该组的计数清零。

固化后的封锁：

| 已固化 | 被永久禁用 |
|---|---|
| 顺从组 | `PUSH BACK`、`SAY THE UNSAID` |
| 攻击组 | `SOFTEN`、`POUR A DRINK`、`AGREE` |
| 失语组 | `SAY NOTHING` |

> **你重复太多次同一种反应，它就成了你的性格。**
> 你不再是在"选"，你是在"变成"。

**保护规则**：如果某个节点所有选项都被禁用，第一个选项会被强制解锁（不会死锁）。

### 8.4 压抑的复利 Compounding Pressure

> **每换一幕**（幕号变化时）：

```
bill = ⌊UNSAID ÷ 2⌋
     + (真我 ≤ 30 ? 3 : 0)
     + (孝 ≥ 85 ? 2 : 0)
压力 += bill
```

三条计费分别对应：**你没说出口的话**、**你已经不当自己了**、**你太乖了**。

一个全程沉默的玩家，UNSAID 会堆到很高，每换一幕被收 5–10 点压力——**这就是「沉默到最后必然崩溃」的机制来源**。

## 9. 人情账本（The Ledger）

### 9.1 数据结构

每个亲戚两份数字：`gave`（给过你多少）和 `owed`（你欠多少）。

**开局预载**（这是你出生到现在的旧账，不是本局产生的）：

| 亲戚 | gave | owed | 差距 |
|---|:--:|:--:|:--:|
| 妈妈 | **312** | 41 | 271 |
| 奶奶 | 214 | 88 | 126 |
| 大舅 | 143 | 0 | 143 |
| 爸爸 | 96 | 12 | 84 |
| 姑妈 | 52 | 45 | 7 |
| 二姨 | 18 | 63 | **−45** |
| 表妹 | 7 | 31 | **−24** |
| 表哥女友 | 0 | 0 | 0 |

### 9.2 每次选择怎么变

```
gave += 账本权重 × 2
owed += round(账本权重 × 0.8)
owed  ≤ gave   （永远不超过）
```

**两边的速率不一样（2 : 0.8），差距会自动扩大。** 这是整个机制的重点。

所以：**你越客气，账本上的差距涨得越快**——而差距最大的那个人，就是摊账本时开口的那个人。

### 9.3 摊账本（The Reckoning，固定第 6 幕）

- 触发对象：**`gave − owed` 最大的那个人**（通常但不必是妈妈）
- 画面上的数字：

```
total = 370000 + gave × 120        // "三十七万"
asked = round(total × 0.22)        // 她替你决定的
```

- 同时展示三行：
  - 她记得的：**+total**（她为你做的）
  - 她替你决定的：**−asked**（你从来没要过的）
  - 你的账本上记的是：**−owed**，以及那句"你们记的不是同一本账"

- 玩家的选择决定结局：
  - 选 `AGREE` 或 `PLAY DUMB` → `reckoning = "take"`（接下）
  - 其它 → `reckoning = "refuse"`（退回）

> **恩情是真的，越界也是真的，它们是同一笔账。**

## 13. 字幕层（The Translation Layer）

**按 Tab** 在三档英文读法之间循环。**它不改变任何游戏数值。**

| 档位 | 英文标签 | 中文标签 |
|---|---|---|
| 1 | `Literal` | 直译 |
| 2 | `Polite` | 客气 |
| 3 | `What she meant` | 真心 |

### 13.1 两种语言模式下的呈现

| 模式 | 大字（主行） | 小字（副行） |
|---|---|---|
| **英文**（默认） | 当前档位的英文 | 档位名称 + 置信度徽章 |
| **中文**（按 L） | 中文原声 | `EN ›` + 当前档位的英文 + 置信度 |

### 13.2 翻译置信度 conf

- 每句台词手工设定，**0–100**
- **`< 60` 时前缀显示红色 `〔?〕`，徽章边框变红**
- **v1.1 起，它参与判定**：

> **`conf < 60` 的台词，玩家如果选「附和」或「示弱」，有 50% 概率是读错了。**
> 读错时：所有正向收益减半，该亲戚好感额外 −6，屏幕上出现一行红字 `You read that wrong.`

```
影响的动词：AGREE 附和 / SOFTEN 示弱
触发概率：50%
后果：正向效果 ×0.5（向上取整）、好感 −6、显示提示
```

**设计意图**：`〔?〕` 不再只是一个装饰符号。它现在说的是实话——**"我不确定这句话是什么意思"**，而你如果硬要按温柔的方向回应，一半的时候会打偏。

实测：400 局里有 647 个节点是 `conf < 60` 的，读错机制在这些节点上生效。

全游戏最低的几句：

| conf | 台词 | 该档位的英文 |
|---:|---|---|
| **12%** | 「你开心就好。」 | *This sentence has twenty meanings and none of them is the literal one.* |
| 30% | 「我们退休了，也不图你什么。」 | *This is true, and it is also the heaviest sentence in this room.* |
| 44% | 「……我以为你不想。」 | *I thought you'd already forgiven me.* |
| 48% | 阳台上的爸爸在打电话 | *He is asking whether the position is still open.* |

**它编码的问题**："我们有多确定听懂了这个人的意思。"
红色 `〔?〕` 是在提醒观众：**这句话往温柔方向翻译，可能是错的。**

### 13.3 真结局的反转

「轮回」结局里字幕层**反转**：中文变成你的声音，英文变成"他"听到的翻译。

```
你说：  「……今年，工作怎么样？」
你的真心： I just want to know if you are okay.   conf 100%
他听到的： So? How's work?
```

## 14. 结局系统

### 14.1 判定流程

```
1. 先单独判断「轮回」(wheelEarned)  → 满足就直接给，跳过下面全部
2. 否则按 ENDING_ORDER 从上往下，第一个满足的胜出
```

`ENDING_ORDER`：

```
flatline > she > flip > severance > became
> invisible > perfect > sensible > outsider > nextyear
> ledgerTaken > ledgerRefused > ordinary
```

**顺序即设计**：描述"你是谁"的结局排在前面，描述"那一幕你选了什么"的结局（账本两个）排在最后。
因为摊账本**每局必定发生**，如果它排在前面就会吞掉一切。

### 14.2 十四个结局

| 序 | 结局 | 中文 | 精确条件 |

### 14.4 策略 → 结局对照（实测）

| 打法 | 主要结果 |
|---|---|
| 一路附和 | 圆满 68.7% / 懂事 29.3% |
| 一路示弱 + 敬酒夹菜 | 懂事 95.7% |
| 一路沉默 | 懂事 63.0% / 外人 19.0% |
| 有「说心里话」就说 | 懂事 59.0% / 普通的年 23.7% |
| 一路硬刚 | 断绝 71.7% / 普通的年 12.3% |
| 专挑最高压力 | **断绝 93.0%** / 抢救失败 1.0% |
| 专挑最高真我 | **断绝 100%** |
| 阴阳怪气 + 卖惨 | 外人 62.7% / 账本·退回 20.0% |
| 全程开玩笑 | 外人 70.3% / 普通的年 13.3% |
| 专挑最低真我（但不硬刚） | 圆满 90.0% / **透明人 4.3%** |
| **沉默 + 卖惨交替** | 懂事 73.7% / **掀桌 6.0%** |

**三处反直觉的地方，值得单独说：**

1. **"一路沉默"不会给你掀桌，它给你「懂事」。**
   因为固化会在连续 3 次沉默后把「沉默」永久禁掉，你被迫改口，压力堆不起来。
   真正通向「掀桌」的是**沉默与卖惨交替**（分属失语组和顺从组，互相重置计数），先把压力堆过 55，再等决堤。

2. **"专挑最高真我"必得断绝。**
   真我最高的动词是硬刚（真我 +12，孝 −12），而孝归零比压力触顶快得多。
   **想保住真我又不毁掉这个家，只能靠「说心里话」（真我 +15 但孝只 −10）——它是唯一一条两边都留得住的路。**

3. **「幽默化解」修好之后，成了最"安全"的进攻性打法。**
   全程开玩笑现在有 70.3% 摸到「外人」——因为真我在涨（+3）、压力在降（期望 −1.8），而面子和孝大致不亏。
   v1.0 时这个数字是 57%，且多数掉进「普通的年」。**一个数字的改动，把一个死掉的按钮变成了流派。**

### 14.5 结局卡上的两块新内容（v1.1）

**① 今晚你做了什么**

统计整局用过的动词，取前三名：

```
WHAT YOU DID TONIGHT
AGREE ×7  ·  SAY NOTHING ×4  ·  POUR A DRINK ×2
```

**这是唯一一处把「你是个什么样的玩家」显式说出来的地方。**
玩家看到 "AGREE ×7" 会比看到任何数字都更具体地明白：哦，我整晚都在点头。

**② 这屋里你没看过的地方**

逃席时只能去一个地方，结局卡会列出剩下三个：

```
IN THE ROOM YOU NEVER LOOKED AT:
the balcony, the bathroom, the seat next to your cousin
```

**这一条是给第二周目用的。** 它在说：这一晚你只看了一半。

### 14.6 最后一句不参与判定

槽位 16「门口最后一句话」**权重被压到 0.35**（v1.2 起），且它**不改变拿到哪个结局**，只决定结局卡的**最后一行**。

每个门口的选项都带自己的 `coda`，例如：

| 门口的选项 | 结局卡的尾行 |
|---|---|
| 「知道了。」转身 | *You did not turn around. The stairwell light went off behind you.* |
| 回头。抱她。 | *You turned back at the door. She was still standing there.* |
| 「妈，那件事，我不怪你。」 | *You said the hardest sentence at the door, which is the worst place to say it and the only place left.* |
| 「我给你写信。真的信。」 | *You promised a letter. You have not written it yet.* |

> **v1.2 修正前的实测**：最后一屏是完整权重的节点，受控实验里 **589/1227（48.0%）的局会被它翻转结局**——与本节和设计文档 §6.1 的验收标准直接冲突。压低权重 + 改成只写尾行之后，这一节成立。
>
> **验收方法**（设计文档 §6.1）：把这一屏删掉，结局应该几乎不变。现在它只贡献 3–4 点量表变化，而门前的最小分差通常在 10 点以上。

## 16. 课堂模式（Classroom Mode）

标题页第二个按钮。与普通模式的差别：

| 项 | 普通 | 课堂 |
|---|---|---|
| 排期 | 16 槽位 | **6 槽位** |
| 内容 | arrive → orange → 2×抽牌 → followup → … | arrive → 抽牌(c2) → xiaochen → toast → **reckoning** → goodbye |
| 字号 | 正常 | `.big` 类：主行 26–40px，选项 19px |
| 时长 | 12–20 分钟 | 约 6 分钟 |
| **投票面板** | 无 | **有**（见下） |

**设计意图**：投影仪 3 米外可读，6 分钟内能走完，且**保留摊账本这一情感高点**。

### 16.1 投票计数（v1.1 新增）

课堂模式下，选项下方会出现一块计票面板：

```
VOTES   · Press 1–4 to count hands · Space to decide
A ████████████████░░░░░░  18
B ██████░░░░░░░░░░░░░░░░   7
C ░░░░░░░░░░░░░░░░░░░░░░   0
D ███░░░░░░░░░░░░░░░░░░░   3
```

| 操作 | 效果 |
|---|---|
| 按 `1`–`6` | 给对应选项 +1 票（禁用选项不计） |
| 按 `空格` / `回车` | **票数最高的选项被执行**；全为 0 时执行 A |
| 条形图 | 最高票那一行变蓝，其余琥珀色 |

**主持人流程**：念题目 → "同意的举手" → 数完按数字键 → 再数下一个 → 空格推进。
票数分布本身就是全场最好笑的时刻（"41 个人里 38 个选了附和"）。

> **建议**：即使有这个面板，也可以直接用肉眼数然后按键——不需要任何网络或学生设备。

### 17.3 效果提示（可关）

每个选项下方显示的是**方向提示，不是数字**：

```
Face↑ Filial↑ Self↓ Stress↓      (↑ 小 / ↓ 小)
Face↑↑ Stress↓↓                    (↑↑ 大，|Δ| ≥ 10)
```

绿色 = 增加，红色 = 减少。**永不显示精确数值**——精确数值会让玩家开始"算"，而"算"会杀死情绪。

**会失败的动词必须显示两种结果**（v1.2 起）：

```
⚄7+  Face↑ Filial↑ Self↑ Stress↓   ✗  Face↓ Filial↓ Self↑ Stress↑
```

- `⚄7+` = 「幽默化解」的掷骰门槛（蓝色）
- `✗` 之后是**失败时的结果**（红色箭头）
- 带 `check` 的节点（8 张旧账 + 摊账本）上，高风险动词同样显示两组
- 效果乘的是**当前对象的系数**，所以同一句话对不同亲戚的提示也不同

> ⚠️ **v1.2 修正**：此前提示**只画成功那一条**。
> 「幽默化解」42% 会失败、失败时面子和孝反而大跌——玩家看到"全涨"却拿到"两跌"，**提示在 42% 的情况下是假的**。
> 这不是数值 bug，是提示 bug。

### 18.1 顺带加固的一处

**`loadMeta()` 不再信任 localStorage。**
原来 `JSON.parse` 出来的东西直接用；如果存档是 `null`、或缺少 `keepsakes` 字段（另一个应用占用了同名键、写入被中断、手动改过），`newRun()` 里的 `META.keepsakes.slice()` 会直接抛错，**整个游戏白屏**。
现在会逐字段校验类型并回落到空存档。

> ⚠️ **v1.1 的这一条只修了一半，v1.2 才补齐**（测试报告 A16）：
> 当时只校验了**类型**（"是不是数组"），没校验**值**（"数组里的东西是不是已知 id"）。
> 于是存档里只要有 `["nope"]` 或 `[null]`，标题页正常显示，但**点「开始这一晚」立刻白屏，且 L / H / Tab / A / Enter / 空格全部无效**——比启动就崩更隐蔽。
>
> v1.2 的修法：
> ```js
> keepsakes: m.keepsakes.filter(k => typeof k==="string" && KEEPSAKES[k]),
> endings:   m.endings.filter(e => ENDINGS.some(x => x.id === e)),
> secrets:   m.secrets.filter(k => typeof k==="string" && ESCAPES[k]),
> ```
> 并把 `startRun()` 整体纳入 `try/catch`，出错时显示一页**带「清除进度并重新开始」按钮**的恢复页，而不是留一个空白。
>
> **为什么这条很现实**：任何一次物件 id 的重命名，都会让全部老存档立刻踩中它。
