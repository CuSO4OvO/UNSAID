# UNSAID v2.0 可玩性复评（玩核）

> 方法：通读 v2.0 源码与机制文档 + 跑通 `tools/` 全套模拟（balance.js 各策略 300–4000 局蒙特卡洛）。
> 结论先行：**v2 的"选择架构"手术是成功的，但"结局生态"是失衡的——14 个结局里至少有 3 个处于临床死亡或盲飞状态，而两个账本/外人结局吃掉了随机局 72% 的份额。**
> 日期：2026-10-10

---

## 1. 核心玩法原子拆解

- **核心动词**：**接**（接住一句带刺的话，并决定以什么姿势付账）。
- **基础规则**：① 五维全部两端危险；② 每句接话同时改五维 + 两本暗账；③ 未说到 5 漏、到 10 决堤；④ 同一姿势连用三次被收走。
- **涌现复杂度**：NPC 系数 × conf 三层听法 × 涟漪，让同一个"接"在不同对象面前成本完全不同。
- **张力结构**：短期（这一回合别撞线）vs 长期（今晚要成为谁 / 三年后要坐上主位）。
- **经典对标**：结构上最像**《扫雷》**——每个节点是一次"有信息但不完全信息"的开格（conf 徽章就是数字），误读与泄漏是雷；元进度层像《Reigns》的王朝轮回。这个对标是成立的，v2 不需要动骨架。

## 2. 核心乐趣诊断

真正好玩的点（一句话）：**"这句话我听懂了几层，决定我付得起哪种回答"**——v2 的 6+2+1、明牌误读、咽回去三处改动都正确地服务了这个点。选择架构不再是问题。

## 3. 可玩性评估

| 维度 | 评级 | 依据 |
|---|---|---|
| 上手门槛 | ✅ 明显改善 | 6+2+1 + 情境槽"她吃这一套"明牌，首回合决策量从 13 选 1 降到 ~7 选 1 |
| 操作爽感与反馈 | ✅ 合格 | 72 条 REACT + 音效 + 压力视觉化，回合有了"空气变化" |
| 决策深度 | ⚠️ 有隐患 | 见问题 2：情境槽自动排序正在替玩家"读人" |
| 重复可玩性 | ❌ 主要短板 | 见问题 1/3/4：结局生态失衡，刷结局的玩家会发现几条路是断的 |
| 目标循环 | ⚠️ 短/中/长期断裂 | 短期（回合）好；中期（一晚）被账本结局垄断；长期（轮回）不可验证 |

## 4. 问题与风险（按严重度）

### 问题 1【致命】轮回线处于"盲飞"状态，且模拟器自己也不知道

- `balance.js` 老兵 lane（wheel open）2000 局 **100% 返回 "(none)"**。原因：v2 加了开局心态选择屏，但模拟器只会点 `.opt` 按钮，**不会点心态按钮**，开局即卡死。也就是说——**自 v2 上线以来，没有任何一次模拟真正打到过结局结算后的轮回判定**。你们最重要的稀有结局，测试覆盖为 0。
- 即便修好模拟器，`wheelEarned` 的窗口也令人怀疑：self≥60 ∧ filial≥55 ∧ flooded ∧ stress<100 ∧ face>0。决堤当场 filial −10，14 槽里要把双维同时维持在高位——**这个窗口是拿 v1 的 15 槽经济定的，v2 砍掉 1 槽后从未重新校准**。
- **改什么**：先修 `balance.js`（开局检测心态屏、自动点第一个心态），再跑一次老兵分布。我预计轮回达成率 <1%，届时要把 flooded 的 filial 惩罚或阈值重新过模拟。

### 问题 2【高】"抢救失败"名存实亡，"掀桌"被"断绝"遮蔽——压力轴没有自己的结局空间

模拟数据：

| 策略 | 结果 |
|---|---|
| max STRESS（全程攒压） | **SEVERANCE 99.7%**，FLATLINE 0% |
| STRESS+FACE 双压专线（n=1500） | SEVERANCE 98.8%，**FLATLINE 仅 0.2%** |
| 随机 4000 局 | THE FLIP 0.4%，FLATLINE 0.03% |

病因：`flip` 的条件是 `stress≥100 || (flooded && stress≥55)`，而对抗系动词 filial −12/次，**孝永远比压力先归零**（severance 排第 4，先判先赢）。FLATLINE 要求"压力 100 的同一瞬间另一维 ≤0"，是一个 razor edge——数值上约等于不可能对齐。
后果：三个"崩溃系"结局（flip / flatline / severance）实际只剩 severance 一个在工作，**压力这条轴攒到头没有自己的死法**。掀桌毛衣这件物件的获取路径事实上被堵死。
- **改什么（二选一）**：
  a. 给压力设"提前引爆"：stress≥100 时**当回合立即结算 flip**，不等回合末与其他维度比较（flip 优先于 severance 的时间窗提前）；
  b. 把 flatline 改成"压力 ≥95 且任一维 ≤15"的红区判定，把 razor edge 改成 red zone。
- 数值均为 [PLACEHOLDER · 需 balance.js 验证：max STRESS 策略下 flip ≥60%，FLATLINE 专线 ≥10%]。

### 问题 3【高】结局分布双头垄断：账本·退回 45% + 外人 27%

随机 4000 局：`ledgerRefused` 45.1% + `outsider` 26.5% = **71.6%**。
- `ledgerRefused` 过宽：`reckoning==="refuse" && self≥55`。refuse = 摊账本上选附和/转移以外的**任何**选项——也就是默认路径。摊账本每晚必触发，它不该是默认落点。
- `outsider` 过宽：`secrets≥3 && unsaid≥8`。14 槽里未说自然涨破 8 是常态，3 个秘密一次出走 + 旧账就够——"你比谁都懂这个家，而你仍是客人"本该是刻意经营的结局，现在是**好奇玩家的垃圾桶**。
- **改什么**：refuse 加一条"且在摊账本上没用沉默以外的温和招"或提高 self 门槛至 65；outsider 的 unsaid 门槛提到 ≥10（要求你憋到决堤边缘仍没说）。[PLACEHOLDER · 目标：随机局两结局合计 ≤40%]

### 问题 4【中】情境槽在替玩家读人

情境槽按 NPC 系数自动排序取前二，≥1.2 挂"她吃这一套"。可读性目的达到了，但**代价是把 v1 最有深度的"读人"学习曲线自动化了**——玩家不再需要记住"大舅好酒、女友吃幽默"，系统直接喂到嘴边。第二年起，情境槽从"辅助"退化为"标准答案"。
- **改什么（低成本）**：第一年挂明牌（教学期），第二年起只排序、**不挂"她吃这一套"标签**，让标签变成玩家自己赚来的直觉；或标签只在 Hints 开启时显示（H 键已有这个开关，接上即可）。

### 问题 5【中】攻略文档 NPC 表整表错位，正在误导玩家

对照 `dump.js` 实测：文档写"妈 clout 5、甩锅 2.5、硬刚 2.0、幽默 0.6、示弱 0.4"——**这行数据实际是奶奶的**（nai: scapegoat 2.5, confront 2.0, joke 0.6；clout 5）；文档里"妈"的真实数据是 clout 4、甩锅 1.4、幽默 0.9、示弱 1.0。逐行比对整张表均有位移。按这张表打"对妈甩锅 2.5"的玩家会被结算打脸。
- **改什么**：文档 NPC 表按 `node tools/dump.js` 输出重排。

### 问题 6【低】"全程硬刚 → 8% 圆满"的反直觉渗漏

always-PUSH-BACK 策略竟有 8% 落在"圆满"。机制上解释得通（僵化收走硬刚后，harness 回退到附和/敬酒把面子孝喂上 70），叙事上甚至有点反讽——但**一个整晚想打架的人有 8% 概率拿到"没有人不高兴，包括你"，说明僵化回退路径的行为没有被结局条件设防**。低优先，可留作"特色"，建议在结局卡上加一句承认这种路径的文案，把 bug 感转成设计感。

## 5. 优化建议汇总

| 优先级 | 事项 | 验证标准 |
|---|---|---|
| 高 | 修 balance.js 心态屏卡死，恢复老兵 lane | 老兵 2000 局能跑出结局分布 |
| 高 | 重校准 wheelEarned 窗口 | 老兵温和均衡流轮回达成 3–8% |
| 高 | 压力轴结局空间（flip 提前结算 / flatline 红区化） | max STRESS → flip ≥60%；专线 FLATLINE ≥10% |
| 高 | 收紧 ledgerRefused / outsider 条件 | 随机局合计 ≤40% |
| 中 | 情境槽明牌降级为教学期/Hints 限定 | 第二年无标签，决策时间不回弹 |
| 中 | 修正攻略文档 NPC 表 | 与 dump.js 逐格一致 |
| 低 | "硬刚转圆满"路径文案承认 | 结局卡加一句 |

## 6. 参考案例

- **《Reigns》**：每张卡牌二元选择、四维任一归零即死。它的教训正好对应问题 2——**每条轴都必须拥有自己的死法**，否则那条轴就不是资源只是装饰。UNSAID 的压力轴目前是装饰。
- **《Slay the Spire》**进阶 20 平衡史：任何"默认路径结局"（如 UNSAID 的账本·退回）一旦被统计发现吞噬分布，第一反应是**收窄触发条件而不是削弱收益**——因为玩家对"拿不到"的怨念远小于"被没收"。问题 3 应照此处理。

## 总评

v2 把"不好玩"的主要病因（选择瘫痪、反馈哑剧、暗骰）都治了，手术成功。**但现在的病人换了个科室：结局生态失衡。** 五维账本的每一笔都记得很认真，可惜结算柜台有三个窗口是关的（轮回盲飞、抢救失败名存实亡、掀桌被断绝抢跑），而人最多的两个窗口（账本·退回、外人）在发免费通行证。

下一版的预算建议全部投给结局生态：先修模拟器（你现在对稀有结局是瞎的），再把压力轴的死法还给压力。
